> 本脚本用于 AI 视频模型生成，顶部为全局生成约束（风格 / 人物 / 一致性 / 真实感 / 负向提示），下方为逐镜画面内容。

## 一、AI 视频生成 · 全局约束（所有镜头共用，不可更改）

### 【风格约束段】
- 画面比例：9:16 竖屏
- 画质：2K 高清，细节丰富，专业摄影级，真实手机拍摄质感
- 整体画风：写实摄影（真实生活记录 / UGC 视频截图感，非广告棚拍）
- 色调：日常暖白调为主，浅色石英石厨房台面 + 原木色 + 米白色；开头痛点镜头（1-5）光线偏冷偏暗、情绪略压抑，镜头 6 起转明亮暖调
- 光线：白天自然光为主，左侧窗户光 + 柔和顶部吸顶灯，阴影柔和，忌无影灯
- 统一风格关键词：写实，真实生活感，自然光线，浅景深，POV 第一视角，生活知识科普短视频风格，电影感自然打光，轻微手机摄影颗粒感

### 【人物一致性约束】
- 严格参考**人物参考图中的同一女性**（30-35 岁，短棕发及耳，圆脸，肤色自然，气质温和亲切）
- 出镜策略：**绝大多数镜头为 POV 第一视角的双手 / 小臂特写**，仅少量镜头露脸（侧脸 / 3/4 侧脸为主，不出现正对镜头的完整正脸）
- 露脸镜头仅 3 个：镜头 1（开场钩子·3/4 侧脸）、镜头 7（科普讲解·3/4 侧脸）、镜头 12（收尾提醒·3/4 侧脸）；其余镜头仍以手部 / 小臂 / 半身为主体
- 人物面部必须与参考图高度一致：短棕发及耳、圆脸、肤色自然、五官端正、神态温和，年龄气质统一

### 【跨分镜视觉一致性约束】
- 所有道具和物品在不同分镜中外观必须完全一致：形状、颜色、纹理、尺寸比例、材质质感保持不变
- 环境与场景在不同分镜中必须统一：**同一间家庭厨房**，浅色石英石台面、浅灰瓷砖墙面、原木色纸巾座、米白橱柜的空间结构与陈设布局保持一致

- 物体之间大小比例符合真实物理比例，在所有分镜中保持统一
- 光源方向（主要来自左侧窗户）、色温、明暗关系在所有分镜中保持一致，阴影方向统一
- 人物手部、袖口穿着在所有分镜中完全统一

### 【生活化真实感优化 · 核心层】

### 【场景真实感增强 · 材质 / 光影 / 空间（厨房）】
- 浅色石英石台面有真实石材颗粒纹理、轻微划痕、水渍印与指尖油脂痕迹，反光不是镜面般完美

- 透视符合手机镜头规律，近大远小自然，物体在台面位置准确，无悬浮穿模；前景 / 背景虚化程度真实，空间纵深明确

- 手部有真实毛孔、指关节褶皱，指甲为自然状态非完美美甲

## 二、视频整体方案

- **主题**：生活冷知识科普——你天天用的厨房抹布，可能比你想的脏多了
- **总时长**：26.0 秒
- **结构类型**：干货科普型（钩子 → 真相揭秘 → 多维度举证 → 结尾一句解决方案）
- **风格调性**：生活知识分享 / 真实厨房记录 / 亲切像朋友提醒 / 不带货，只讲真相
- **钩子设计**：0.5s 开场，随手捏起一块看似"还行"的抹布反问"你家这块抹布，用了几天了？"
- **核心亮点**：用微距、对比、POV 操作一步步揭开抹布藏污纳垢、细菌滋生、交叉污染、毛絮残留、洗不干净的真相，让观众看完觉得"妈呀我家也这样"，最后一句点出厨房纸巾可以解决
- **创意手法**：微距 / 极致特写、POV 第一视角、碎片化举证蒙太奇、对比分镜（用前 vs 用后）、慢镜头细节放大、动静对比
- **产品露出**：仅最后 2 个镜头（镜 10、11）出现厨房纸巾，一句口播带过，不做卖点展开
- **口播总字数**：约 110 字（生活化初稿，阶段二可继续精简）
- **出镜策略**：绝大多数镜头为 POV 双手特写；仅少量镜头（镜 1 / 镜 7 / 镜 12）露 3/4 侧脸，自然像博主对着镜头分享；人物形象以**参考图片人物**为准

### 镜头 1：捏起抹布反问（钩子 · 露脸）

- **时间**：0.0s - 0.5s（时长 0.5s）
- **叙事功能**：开场钩子（提问代入）
- **景别**：中近景（人物上半身 + 抹布）
- **角度**：平视微俯约 5 度
- **运镜**：微手持，自然轻微晃动，像手机自拍视角
- **人物**：参考图片人物（3/4 侧脸，露出右半张脸，不是完全正脸正对镜头）
- **关键道具**：一块用了几天的灰白棉抹布（看似"还能用"，细看有使用痕迹）

【画面内容段】
- 场景：家庭厨房浅色石英石台面前，白天，日常暖白光线；背景是厨房台面和橱柜虚化；同一间厨房
- 人物动作：参考图片人物（30-35 岁，短棕发及耳，圆脸，穿燕麦色七分袖针织开衫 + 白 T 恤，戴小珍珠耳钉）以 3/4 侧脸角度出现在画面右侧（手机自拍视角），身体微微前倾，右手抬起、拇指食指捏着一块灰白抹布一角举到镜头前，眉头微皱、眼神带着"你看这东西"的好奇+嫌弃表情，嘴唇微张正在说话；动作自然随意，像对着镜头跟朋友聊天
- 构图：中近景，平视微俯约 5 度，三分法构图，人物 3/4 侧脸在画面右侧，手中举起的抹布在画面中央偏左，左侧留出厨房背景空间
- 运镜感：微手持轻微呼吸晃动，手机自拍的真实感，动作瞬间凝固
- 细节：人物面部与参考图一致（短棕发、圆脸、肤色自然、温和神态）；抹布有淡淡的使用痕迹；针织开衫纹理真实；背景厨房环境虚化自然

- **转场方式**：开场
- **口播内容**：你家这块抹布，用了几天了？
- **导演意图**：开场就露脸，用"真人提问 + 举着抹布"的方式快速建立亲切感和博主分享感，让观众愿意停下来看下去

### 镜头 2：微距·抹布纤维里嵌满油污残渣

- **时间**：0.5s - 2.0s（时长 1.5s）
- **叙事功能**：问题揭示（真相 1：藏污纳垢）
- **景别**：微距 / 极致特写
- **角度**：正俯视约 70 度
- **运镜**：固定镜头（微距机位），画面略微推进
- **人物**：无（纯道具微距）
- **关键道具**：抹布（微距下纤维、油污、食物残渣清晰可见）

【画面内容段】
- 场景：同一块抹布平铺在浅色石英石台面上，冷调略暗光线（突出脏污细节）
- 人物动作：无人物动作；微距下可清晰看到棉纤维缝隙里嵌着暗黄色油污、细小食物残渣、灰黑色污渍，布面已经板结发黏，局部颜色发灰发暗，静态呈现（画面略微推进，细节逐渐清晰）
- 构图：微距，正俯视约 70 度，中心构图，抹布纤维纹理充满画面
- 运镜感：固定机位，画面缓慢轻微推进（推镜感），越推细节越明显
- 细节：极致微距下棉纤维纹理清晰，油污颗粒和食物残渣嵌在缝隙里，侧光让油污产生微小高光，纹理凹凸感真实

- **转场方式**：切（从上镜提起的抹布直接切到微距特写）
- **口播内容**：看着好像还行，是吧？你凑近看——
- **导演意图**：把"你以为还干净"的抹布放大给观众看，用微距把肉眼看不到的油污残渣拍出来，是第一个"卧槽"的科普点

### 镜头 3：擦完灶台擦盘子（交叉污染）

- **时间**：2.0s - 3.8s（时长 1.8s）
- **叙事功能**：问题揭示（真相 2：交叉污染）
- **景别**：特写（手部 POV 操作）
- **角度**：正俯视约 75 度（POV 第一视角）
- **运镜**：微手持，跟随擦拭动作小幅跟拍
- **人物**：参考图片人物（仅右手入画，POV 视角）
- **关键道具**：抹布、白瓷碗、灶台

【画面内容段】
- 场景：厨房台面·白天；左侧是灶台面（有轻微油污痕迹），右侧放着干净白瓷碗；暖白日常光线；同一间厨房，浅色石英石台面
- 人物动作：POV 第一视角（正俯视约 75 度，像低头看自己的手）；女性右手（参考图片人物的手，袖口一致）抓着同一块抹布，先在左侧灶台上从后往前擦一下，抹布顺势不停，直接擦到右侧白瓷碗的碗沿上，动作连贯自然；擦完碗沿后，碗沿上留下一道淡淡的油痕与两根细小毛絮
- 构图：特写，正俯视约 75 度，引导线构图，抹布从灶台擦向碗盘形成"灶台→餐具"视觉流
- 运镜感：POV 微手持，跟随擦拭动作小幅跟拍
- 细节：白瓷碗沿上淡淡的油痕和毛絮清晰可见；动作就是很多家庭真实的"一块抹布走天下"的用法

- **转场方式**：切
- **口播内容**：你是不是擦完灶台又擦碗？细菌直接带到餐具上，交叉污染啊
- **导演意图**：把很多家庭都有的习惯——一块抹布到处擦——直接拍出来，点明"交叉污染"，但用大白话讲，不说教

- **景别**：特写

- **关键道具**：掉毛的抹布、黑色光面台面上的白色细毛絮

【画面内容段】
- 场景：厨房黑色钢化玻璃灶台 / 不锈钢水槽边缘，白天；黑色背景上白毛絮特别显眼；侧光打亮毛絮
- 人物动作：女性右手（袖口一致）捏着抹布一角，从左向右擦过黑色光面后离开；黑色表面上留下一层细细的白色毛絮和掉落的纤维；镜头静止在毛絮上约 0.5 秒，让观众看清楚
- 构图：特写，微微俯视约 20 度，三分法构图，左侧黑台面满是白毛絮、右侧是抹布一角
- 运镜感：固定机位，动作完成后画面静止
- 细节：白色细毛絮散落在黑色光滑表面上，侧光让毛絮立起来，清晰刺眼；抹布边缘起毛掉线

- **转场方式**：切
- **口播内容**：擦完还掉一桌子毛絮，越擦越脏
- **导演意图**：用黑色背景 + 白毛絮的强烈对比，把"掉毛"这个常见但容易忽视的问题拍得一目了然

### 镜头 5：搓洗抹布也洗不干净

- **时间**：5.0s - 6.2s（时长 1.2s）
- **叙事功能**：问题揭示（真相 4：洗不干净）
- **景别**：近景（POV 水槽边双手）
- **角度**：俯视约 50 度（POV 第一视角）
- **运镜**：微手持，跟随搓洗动作轻微晃动
- **人物**：参考图片人物（双手入画，POV 视角）

## 五、整体节奏分析

全片节奏是"快→慢→快→慢"的科普讲解节奏。**0-5s 钩子 + 两个真相**节奏偏快，快速抛出"凑近看""交叉污染"两个直观画面抓住注意力。**5-11s 节奏放慢**，从"洗不干净""晾不干"的生活化画面过渡到"比马桶还多细菌"的科普数据点，是全片记忆点最集中的段落，用慢节奏让信息"沉"进观众脑子里。**11-17.5s 节奏再加快**——拿起自家抹布对照 → 传统解决方法（勤换 + 煮沸），是从"知识"到"我该怎么办"的落地。**17.5-26s 再次放慢**，从抽一张纸巾 → 用完即扔 → 5 秒随手收拾台面长镜头收尾，用舒缓的、生活化的画面把情绪落到"省心、干净"上，最后一句收藏号召自然收口，余味悠长。

全程是**朋友聊天式的科普**，不是老师讲课，也不是带货推销——产品只在最后两镜出现，作为"嫌麻烦的话还有这个办法"的轻描淡写选项。

## 六、全片声音设计总览

- **背景音乐风格**：轻松温暖的尤克里里 + 轻钢琴，生活化日常感，没有带货感的强烈节拍
- **关键音效节点**：
  1. 0.5s 微距切入时一个轻微上扬音效（暗示"凑近看"）
  2. 8s 科普数据点时，BGM 音量略降，突出口播
  3. 17.5s 抽纸巾时清脆的"唰"一声（自然真实，不是广告感）
- **口播整体语气**：像闺蜜 / 邻居姐姐聊天分享冷知识，好奇、惊讶、真诚提醒，不说教、不贩卖焦虑
- **声音记忆点**："比马桶还多"这句的语气停顿 + 最后"回去看看你家那块抹布"的亲切提醒
